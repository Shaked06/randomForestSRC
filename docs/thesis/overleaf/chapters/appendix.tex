\section{Numerical provenance}
Results are read from the isolated run directory
\begin{center}
\path{simulations/reruns/2026-11-06-1802cc3/}
\end{center}
Its manifest records source hashes and installed-package fingerprints.
The six saved result objects contain 100 replications each. The
generator \path{docs/thesis/generate_results_tables.R} reads these
objects, checks their run size, finite scores, zero-entry agreement,
and package provenance, then generates the LaTeX tables. Figures are
copied from the same refreshed summary. Original historical result
objects are not used by the current table generator.
